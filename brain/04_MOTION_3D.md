# Motion e 3D

Camadas:

1. CSS para hover, foco, grids e loops;
2. Motion para entradas e sequência;
3. Lenis para continuidade;
4. React Three Fiber para cenas.

Regras: reduced motion, DPR limitado, conteúdo fora do Canvas, fallback visual,
uma cena pesada por dobra e teste em celular.

O Motion.so mostrado no vídeo é valioso para gerar vídeos via Claude/MCP. Ele
complementa o SiteOps; não é o motor de animação do site.
