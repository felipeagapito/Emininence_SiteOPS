# Eminence SiteOps

Sites de alta conversão para prestadores locais, conectados ao WhatsApp e construídos para transformar confiança em pedidos de orçamento.

## Experiências incluídas

- Home comercial da Eminence SiteOps
- Demo Prime Calhas: telhados, calhas e impermeabilização
- Demo Vetro: vidraçaria, box e esquadrias

## Stack

Next.js 16, React 19, TypeScript, Tailwind CSS 4 e Vinext para publicação no Cloudflare Workers via ChatGPT Sites.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Validação

```bash
npm run lint
npm run build
npm test
```

> As marcas, métricas e informações exibidas nos dois modelos são demonstrativas.
